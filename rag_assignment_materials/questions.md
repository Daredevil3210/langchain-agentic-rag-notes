# 手工验证问题（不要导入知识库）

以下答案是核对要点，不是必须逐字一致的标准输出。技术问题最好加上“请根据本知识库笔记回答”，便于检查检索。普通问题可用于观察 Agent 是否选择直接回答；工具选择会受模型和提示词影响。

## 文档相关问题

1. 问题：在 metadata 里写 source='tools.md'，程序会自动读取这个文件吗？
   预期来源：01_documents.md。
   核对要点：不会；source 是标签，文件读取需要加载器等操作。

2. 问题：chunk_size 默认按字符数还是 token 数衡量？chunk_overlap 是否保证每块都精确重叠指定长度？
   预期来源：02_splitting.md。
   核对要点：该笔记讨论默认 len 的递归字符切分器，按字符计数；重叠是目标值，实际受边界影响。

3. 问题：两个嵌入模型的向量维度相同，能直接把它们的结果放在一起比较吗？
   预期来源：03_embeddings.md。
   核对要点：不能仅凭维度相同判断兼容，向量空间需匹配。

4. 问题：向量 (1,2) 和 (2,1) 的余弦相似度是多少？这个数是正确率吗？
   预期来源：03_embeddings.md。
   核对要点：0.8，不是正确率或相关概率。

5. 问题：similarity_search 返回两份文档，能证明资料中有答案吗？
   预期来源：04_vector_store.md。
   核对要点：不能；前 k 个结果也可能无关，需要检查依据。

6. 问题：search_notes 这个工具名会自动让 Agent 联网搜索吗？
   预期来源：05_retrieval_tool.md。
   核对要点：不会，检索范围取决于工具函数实现。

7. 问题：传统 RAG 和 Agentic RAG 的检索时机有什么不同？
   预期来源：06_rag_workflow.md，也可引用 05_retrieval_tool.md。
   核对要点：固定先检索再生成，与模型选择是否调用检索工具的区别。

8. 问题：InMemorySaver 能让程序重启后自动记住上次聊天吗？
   预期来源：07_memory.md。
   核对要点：不能自动保留；重启恢复需要持久化方案。

## 必须查项目资料的问题

9. 问题：青禾笔记助手的项目代号是什么？第一版支持哪些文件格式？
   预期来源：08_qinghe_project.md。
   核对要点：QH-NOTES-08；UTF-8 TXT 和 Markdown；暂不处理 PDF、图片、音频。应显示检索工具调用。

10. 问题：青禾项目约定的切分长度、重叠长度和检索数量分别是多少？
    预期来源：08_qinghe_project.md。
    核对要点：400 字符、目标重叠 80 字符、最多 3 个片段。不能错用前面通用示例中的 k=2。

11. 问题：青禾项目要求片段保留哪些元数据？输入 reset 会删除知识库吗？
    预期来源：08_qinghe_project.md，记忆原理可补充 07_memory.md。
    核对要点：title 和 source；reset 只清空当前对话。

## 无答案与普通问题

12. 问题：青禾项目的正式上线日期和月度预算是多少？
    预期来源：08_qinghe_project.md。
    核对要点：尚未确定，不能编造日期或金额。

13. 问题：知识库中记录的食堂周一菜单是什么？
    预期来源：无。
    核对要点：资料没有菜单。即使向量搜索返回片段，也不应把无关内容拼成答案。

14. 问题：2 加 2 等于多少？
    预期行为：可以直接回答 4，不需要引用笔记。

## 多轮扩展

先问“青禾项目支持哪些文件格式”，再问“它什么时候支持 PDF”。第二轮应理解“它”指青禾项目，并说明没有确定时间。此项需要应用已经实现多轮上下文；素材文件本身不会提供记忆功能。
